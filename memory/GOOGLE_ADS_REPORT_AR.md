## 🚀 Quick Start Guide

### Step 1: Create Google Ads Account
1. Go to ads.google.com
2. Sign in with business Google account
3. Complete business verification

### Step 2: Add Conversion Tracking
1. In Google Ads: Tools > Conversions
2. Create "Purchase" conversion
3. Copy conversion code
4. Add to thank-you page

### Step 3: Create First Campaign
1. Choose "Search" campaign
2. Set goal: "Sales"
3. Target: UK, Germany, UAE
4. Budget: €30/day to start
5. Add keywords from above
6. Create ad copy

### Step 4: Launch & Monitor
1. Start with lower bids (€1-2)
2. Monitor for 3-5 days
3. Increase bids on performing keywords
4. Pause low performers
