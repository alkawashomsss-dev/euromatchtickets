## Setup Steps

### Step 1: Create Campaign
1. Click "New Campaign" in Google Ads
2. Select "Sales" as goal
3. Choose "Search Network"
4. Enter: `euromatchtickets.com`

### Step 2: Setup Ad Groups
1. Copy keywords from this document
2. Select "Phrase Match" or "Exact Match"
3. Set daily budget

### Step 3: Create Ads
1. Copy ad copy from this document
2. Add 3-5 headlines
3. Add 2 descriptions
4. Verify URLs work

### Step 4: Review & Launch
1. Review all settings
2. Click "Publish Campaign"
3. Wait for approval (24-48 hours)
